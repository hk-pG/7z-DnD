# 7z-DnD

圧縮ファイルをウィンドウにドラッグ＆ドロップすると、**そのファイルと同じ場所に同名サブフォルダを作り**、7-Zip で解凍する Windows アプリです。

> **非公式ツールです。** 本プロジェクトは [7-Zip](https://www.7-zip.org/) / Igor Pavlov 氏とは無関係です。7-Zip は別途インストールが必要な依存コンポーネントです。

## 前提

- Windows 11
- [7-Zip](https://www.7-zip.org/) が **Program Files** にインストール済み（既定: `C:\Program Files\7-Zip\7z.exe`）
- .NET 10 ランタイム（開発・実行時）

アプリは既定で `Program Files` / `Program Files (x86)` の `7z.exe` のみを自動採用します。PATH 上の別バイナリだけが見つかった場合は、警告ダイアログで明示確認しない限り使いません。

## 使い方

1. アプリを起動する
2. 圧縮ファイル（`.zip` / `.7z` / `.rar` など）をウィンドウへドロップ
3. アーカイブと同じ場所に `ファイル名/` サブフォルダが作られ、その中に展開される  
   （例: `C:\data\sample.zip` → `C:\data\sample\`）
4. パスワード保護アーカイブは、対象ファイル名付きの入力ダイアログが出る（キャンセルはそのファイルのみ失敗）

EXE にファイルをドラッグして起動しても解凍します。

ログは画面表示に加え、`%LocalAppData%\7z-DnD\logs\` にも保存されます（アプリが落ちても残ります）。**ログにはフルパスが含まれることがあります。**

## 信頼モデル（重要）

- **信頼できるアーカイブだけ**を解凍してください。悪意のあるアーカイブは、パス操作（zip-slip）やリソース枯渇（zip bomb）などで被害を与え得ます。
- 本アプリは解凍後に出力フォルダ内を走査し、解決後パスが出力先を逃げるエントリを削除して失敗扱いにします。ただし **7z が出力先の外へ直接書いたファイルまでは完全には防げません**（完全な防止には 7z 本体側の制御が必要です）。
- **Zip bomb**（極端な展開サイズ）に対する専用タイムアウトや容量上限はありません。不審な巨大アーカイブは解凍しないでください。

## 既知の制限

- パスワードは 7z へ `-p` でプロセスのコマンドライン引数として渡します。**同一マシンの管理者や他プロセスから見える可能性があります。** 共有 PC では注意してください（7z DLL API への移行は未実装）。
- コード署名（Authenticode）は付与していません。配布バイナリを検証する場合はソースから自前ビルドしてください。

脆弱性の報告方法は [SECURITY.md](SECURITY.md) を参照してください。ライセンスは [MIT](LICENSE) です。

## 開発

```powershell
dotnet run
```

単一 EXE の発行:

```powershell
dotnet publish -c Release -o publish
```

`publish\7z-DnD.exe` が生成されます。
